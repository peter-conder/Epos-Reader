# Epos-Reader

A reader for the Aeneid, Iliad and Odyssey in the original language: Scansion, Word cards with Lemma and Morphology, Parallel translation, Splits, Notes, Bookmarks and the Notebook. Terms are defined in `CONTEXT.md`.

## Agent skills

### Issue tracker

Issues are tracked as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), recorded as `Status:` lines in issue files. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root, created only when needed. See `docs/agents/domain.md`.
